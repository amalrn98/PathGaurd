# Code of Conduct

PathGuard aims to be a respectful, constructive, and welcoming open-source project. Participation in project spaces, including issues, pull requests, and discussions, is expected to meet these standards.

## Expected behaviour

- Be respectful and considerate.
- Discuss ideas and technical decisions in good faith.
- Give actionable feedback and accept constructive criticism. Hard criticism of the protocol and the code is welcome, and it should be aimed at the work, not the person.
- Respect different backgrounds, experience levels, and viewpoints.
- Keep discussions focused on improving the project.

## Unacceptable behaviour

Harassment, discrimination, personal attacks, intimidation, doxxing, and deliberately disruptive conduct are not acceptable. Publishing another person's private information without permission is not acceptable.

## Reporting

If you experience or witness behaviour that violates this Code of Conduct, contact the maintainer privately on Discord at **@mythicavalon**, or through the [maintainer's GitHub profile](https://github.com/amalrn98). Please include a link to the relevant issue, pull request, or discussion and a concise description.

Reports will be reviewed and handled as discreetly as reasonably possible. The maintainer may remove content, close discussions, or restrict participation when necessary to protect the project community.

## Scope

This Code of Conduct applies to project repositories and spaces used to discuss or contribute to PathGuard.
